# Local Knowledge Engine

Reusable local Q&A base app. Upload a zip of source files, ask questions, get cited answers. Fork this to build custom knowledge apps (first planned use case: a game guide).

**Status:** planning only. No application code yet.

Read the full build plan: [PLAN.md](./PLAN.md)

When implementation starts, this README will cover install (Ollama + Python), running the UI, ingesting a zip, and creating a use-case fork.
